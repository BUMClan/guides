# Guides

## HaloX (Wineskin)

Automated macOS builds of the classic *Halo: Combat Evolved* (Windows edition)
via Wine + Wineskin – ready-to-run `HaloX.app` for **Intel** and **Apple
Silicon** (Rosetta 2), locked to the verified WineskinCX 23.7.1 engine.

→ **Repo:** [github.com/BUM-MasterMike/HaloX](https://github.com/BUM-MasterMike/HaloX)
